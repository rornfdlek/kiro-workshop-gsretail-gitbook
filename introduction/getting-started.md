# 환경 준비

## 1. Kiro 설치 확인

[https://kiro.dev/](https://kiro.dev/) 에서 Kiro를 다운로드하고 설치합니다.

## 2. Node.js 확인

```bash
node --version
# v18 이상이어야 합니다
npm --version
```

## 3. Kiro에서 새 프로젝트 열기

Kiro를 실행하고 새 폴더를 열어 프로젝트를 시작할 준비를 합니다.
