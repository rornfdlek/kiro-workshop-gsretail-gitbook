# Module 3: 구현 및 실행

이 모듈에서는 Kiro가 정의한 태스크를 실행하여 실제 애플리케이션을 구현하고, 로컬에서 실행해봅니다.

## 학습 목표

* Kiro의 태스크 기반 자동 코드 생성 체험
* 생성된 코드 검토 및 이해
* 로컬 환경에서 애플리케이션 실행 및 테스트

## 모듈 구성

1. [태스크 실행 - 코드 생성](build.md) — 태스크를 순서대로 실행하여 코드를 생성합니다
2. [애플리케이션 실행](run.md) — 백엔드와 프론트엔드를 실행하고 결과를 확인합니다
