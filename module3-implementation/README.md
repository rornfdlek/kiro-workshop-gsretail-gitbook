# Module 3: 구현 및 실행

## 이 모듈에서 할 것

드디어 가장 재미있는 부분입니다! 🎉

이전 모듈에서 Kiro가 만들어준 **태스크(할 일 목록)**를 하나씩 실행하면, Kiro가 알아서 코드를 작성합니다. 그리고 완성된 시스템을 브라우저에서 직접 확인해봅니다.

```mermaid
graph LR
    A["태스크 실행<br/>체크박스 클릭!"] --> B["Kiro가 코드 작성<br/>자동으로 파일 생성"]
    B --> C["브라우저에서 확인<br/>실제로 동작!"]

    style A fill:#43e97b,color:#fff
    style B fill:#4facfe,color:#fff
    style C fill:#fa709a,color:#fff
```

{% hint style="info" %}
여러분이 할 일은 **체크박스를 클릭하는 것**과 **브라우저에서 결과를 확인하는 것**뿐입니다!
{% endhint %}

## 모듈 구성

1. [태스크 실행 - 코드 생성](build.md) — 체크박스를 클릭해서 코드를 만듭니다
2. [애플리케이션 실행](run.md) — 완성된 시스템을 브라우저에서 확인합니다
