# 태스크 실행 - 코드 생성

## 태스크 실행하기

`tasks.md` 파일에 정의된 태스크들을 순서대로 실행합니다. Kiro의 태스크 패널에서 각 태스크의 체크박스를 클릭하면 해당 태스크의 코드가 자동 생성됩니다.

{% hint style="warning" %}
태스크는 반드시 **순서대로** 실행해야 합니다. 이전 태스크의 결과물에 다음 태스크가 의존하기 때문입니다.
{% endhint %}

## 실행 과정

### 1단계: 프로젝트 초기화 태스크

첫 번째 태스크를 실행하면 Kiro가 다음을 생성합니다:

* `package.json` (backend/frontend)
* TypeScript 설정 파일
* 프로젝트 디렉토리 구조

### 2단계: 데이터베이스 태스크

* SQLite 스키마 파일 생성
* 시드 데이터 (샘플 상품: 도시락, 음료, 과자 등)
* DB 초기화 스크립트

### 3단계: Backend API 태스크

* Express 서버 설정
* REST API 엔드포인트 (상품, 재고, 발주, 판매)
* 발주량 자동 계산 로직

### 4단계: Frontend 태스크

* React 컴포넌트 구조
* 페이지 라우팅
* API 연동

### 5단계: 대시보드 및 시뮬레이터 태스크

* Chart.js 기반 판매 분석 차트
* 판매 데이터 시뮬레이터 UI
