# 태스크 실행 - 코드 생성

## 어떻게 실행하나요?

`tasks.md` 파일에 있는 **체크박스를 순서대로 클릭**하면 됩니다!

각 체크박스를 클릭하면 Kiro가 해당 태스크의 코드를 자동으로 작성합니다. 마치 레시피의 각 단계를 실행하는 것과 같습니다.

{% hint style="warning" %}
⚠️ **순서가 중요합니다!** 반드시 **위에서 아래로 순서대로** 실행하세요. 2단계가 끝나야 3단계에서 필요한 파일이 만들어지기 때문입니다. (기초공사 전에 지붕을 올릴 수 없는 것과 같아요!)
{% endhint %}

{% hint style="info" %}
태스크 수가 서브태스크를 포함해 과도하게 많이 생성된 경우, 아래와 같이 키로에게 부탁하세요!

```
Sub Task 없이 Main Task로만 단계를 5개로 정의해주세요.
```
{% endhint %}

## 실행 과정 미리보기

각 태스크가 실행되면 Kiro가 어떤 일을 하는지 간단히 알아봅시다:

### 1️⃣ 프로젝트 초기화 + 데이터베이스

> 건물의 **터 다지기 + 기초공사** 단계

* 프로젝트의 기본 폴더 구조와 설정 파일을 만듭니다
* 상품, 재고, 판매, 발주 테이블을 만듭니다
* 삼각김밥, 도시락 등 **샘플 상품 데이터**를 넣어줍니다

### 2️⃣ 서버(Backend) 구현

> 건물의 **배관/전기 공사** 단계

* 데이터를 처리하는 서버 기능을 만듭니다
* API 엔드포인트를 구성합니다

### 3️⃣ 화면(Frontend) 구현

> 건물의 **인테리어** 단계

* 상품 목록, 재고 현황 등 웹 페이지를 만듭니다
* 발주 승인 버튼 등 사용자 인터페이스를 구성합니다

### 4️⃣ 발주 계산 + 대시보드

> 건물의 **핵심 설비 + 가구** 단계

* 발주량 자동 계산 로직을 만듭니다
* 판매 분석 차트를 만듭니다

### 5️⃣ 시뮬레이터

> 건물의 **테스트 운영** 단계

* 테스트용 가상 판매 데이터 생성 기능을 만듭니다

## 문제가 생기면?

<details>

<summary>🆘 태스크 실행 중 오류가 발생했어요!</summary>

걱정하지 마세요! Kiro에게 알려주면 됩니다:

{% code title="📋 복사해서 붙여넣기" %}
```
방금 태스크 실행 중 오류가 발생했어요. 수정해주세요.
```
{% endcode %}

Kiro가 오류를 자동으로 분석하고 수정합니다. 수정이 완료되면 해당 태스크를 다시 실행해보세요.

</details>

<details>

<summary>⏰ 태스크 실행이 너무 오래 걸려요</summary>

각 태스크는 보통 **1\~3분** 정도 걸립니다. 5분 이상 진행이 없다면:

1. Kiro 채팅에 "현재 진행 상황을 알려주세요"라고 물어보세요
2. 그래도 안 되면, 진행자에게 도움을 요청하세요

</details>

{% hint style="success" %}
모든 태스크의 체크박스가 ✅로 바뀌면 **코드 생성 완료!** 다음 단계에서 실제로 실행해봅시다!
{% endhint %}
