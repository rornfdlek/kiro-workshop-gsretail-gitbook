# 애플리케이션 실행

## 실행 요청

모든 태스크가 완료되면, Kiro에게 애플리케이션 실행을 요청합니다.

{% code title="프롬프트" %}
```
백엔드랑 프론트엔드를 실행시킨다음 접속주소를 알려주시겠어요?
```
{% endcode %}

Kiro가 자동으로:

1. 필요한 패키지를 설치 (`npm install`)
2. 백엔드 서버를 시작
3. 프론트엔드 개발 서버를 시작
4. 접속 URL을 알려줍니다

## 애플리케이션 확인

브라우저에서 Kiro가 알려준 주소(보통 `http://localhost:3000` 또는 `http://localhost:5173`)에 접속합니다.

### 확인할 기능들

| 기능 | 확인 방법 |
|------|-----------|
| 상품 목록 | 메인 페이지에서 편의점 상품 목록이 표시되는지 |
| 재고 현황 | 각 상품의 현재 재고 수량 확인 |
| 자동 발주 | 발주 자동 생성 기능이 동작하는지 |
| 발주 승인/수정 | 생성된 발주를 승인하거나 수량 수정 |
| 판매 시뮬레이터 | 가상 판매 데이터 생성 후 재고 변화 확인 |
| 대시보드 | Chart.js 차트가 정상 렌더링되는지 |

## 문제 해결

실행 중 오류가 발생하면 Kiro에게 직접 알려주세요:

{% code title="프롬프트" %}
```
실행했는데 오류가 발생했어요. 터미널에 이런 에러가 나옵니다: [에러 메시지를 복사해서 붙여넣기]
```
{% endcode %}

{% hint style="info" %}
Kiro는 에러 메시지를 분석하고 자동으로 코드를 수정합니다. 수정 후 다시 실행을 요청하세요.
{% endhint %}

## 추가 실습 (시간이 남는 경우)

시간이 남는다면 아래와 같은 기능 추가를 요청해볼 수 있습니다:

<details>

<summary>추가 기능 요청 예시</summary>

**CSV 다운로드:**

```
발주 내역을 CSV로 다운로드하는 기능을 추가해주세요.
```

**카테고리 필터:**

```
카테고리별로 필터링할 수 있는 기능을 상품 목록에 추가해주세요.
```

**재고 부족 표시:**

```
재고가 최소 유지 수량 이하인 상품을 빨간색으로 표시해주세요.
```

</details>
