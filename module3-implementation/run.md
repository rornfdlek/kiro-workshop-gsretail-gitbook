# 애플리케이션 실행

## 드디어 실행합니다! 🚀

Kiro에게 실행을 요청합니다:

{% code title="📋 복사해서 붙여넣기" %}
```
백엔드랑 프론트엔드를 실행시킨다음 접속주소를 알려주시겠어요?
```
{% endcode %}

Kiro가 자동으로:

1. 필요한 도구들을 설치하고 (`npm install`)
2. 서버를 시작하고
3. 웹 화면을 시작하고
4. **접속할 수 있는 주소**를 알려줍니다

{% hint style="info" %}
보통 `http://localhost:3000` 또는 `http://localhost:5173` 같은 주소가 나옵니다. 이 주소를 **웹 브라우저 주소창에 복사해서 붙여넣기**하면 됩니다!
{% endhint %}

## 브라우저에서 확인해보기

웹 브라우저(Chrome, Edge 등)에서 Kiro가 알려준 주소에 접속합니다.

### 이런 화면들이 보여야 합니다:

| 확인할 것        | 어떻게 확인?      | 잘 되면 보이는 것           |
| ------------ | ------------ | -------------------- |
| 📋 **상품 목록** | 메인 화면        | 삼각김밥, 도시락 등 상품 리스트   |
| 📦 **재고 현황** | 재고 메뉴 클릭     | 각 상품의 남은 수량          |
| 🤖 **자동 발주** | 발주 메뉴 클릭     | 자동 계산된 발주 수량         |
| ✅ **발주 승인**  | 발주 항목의 승인 버튼 | 상태가 "대기" → "승인"으로 변경 |
| 🎮 **시뮬레이터** | 시뮬레이터 메뉴     | 버튼 누르면 가상 판매 데이터 생성  |
| 📊 **대시보드**  | 대시보드 메뉴      | 판매 현황 차트/그래프         |

{% hint style="success" %}
위 기능들이 동작한다면 **축하합니다! 발주 자동화 시스템을 성공적으로 만들었습니다!** 🎉
{% endhint %}

## 문제가 생기면?

실행 중 오류가 나면, 에러 메시지를 그대로 Kiro에게 전달하면 됩니다:

{% code title="📋 복사해서 붙여넣기 (에러 메시지 부분을 교체)" %}
```
실행했는데 오류가 발생했어요. 터미널에 이런 에러가 나옵니다: [에러 메시지를 여기에 복사해서 붙여넣기]
```
{% endcode %}

{% hint style="info" %}
Kiro는 에러 메시지를 분석해서 자동으로 코드를 수정합니다. 수정 후 다시 실행을 요청하면 됩니다.
{% endhint %}
