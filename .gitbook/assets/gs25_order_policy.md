# GS25 발주 정책 가이드

## 자동 발주 기본 규칙

### 발주 산출 공식
자동 발주량 = (일 평균 판매량 × 리드타임) + 안전재고 - 현재고

### 리드타임 기준
- 도시락/신선식품: 1일 (매일 배송)
- 음료/과자: 2일 (격일 배송)
- 생활용품: 3일 (주 2회 배송)

### 안전재고 기준
- 도시락: 일 평균 판매량의 20%
- 음료: 일 평균 판매량의 30%
- 과자: 일 평균 판매량의 25%
- 생활용품: 일 평균 판매량의 50%

## 발주 승인 프로세스
1. 시스템이 자동 발주량 산출
2. 점주가 발주 내역 검토
3. 수량 조정 가능 (±50% 범위 내)
4. 최종 승인 후 발주 확정
5. 배송 센터에서 다음 배송일에 배송

## 특수 상황 발주
- 행사 기간: 해당 상품 발주량 1.5배 적용
- 날씨 연동: 기온 30도 이상 시 음료 카테고리 1.3배
- 비 예보 시: 우산, 우비 카테고리 자동 발주량 증가
- 주말/공휴일: 도시락 카테고리 1.2배 적용

## 폐기 관리
- 유통기한 임박 상품 (4시간 이내): 자동 할인 적용 (30%)
- 유통기한 만료 상품: 즉시 폐기 처리
- 월간 폐기율 5% 이상 시 발주량 자동 조정
