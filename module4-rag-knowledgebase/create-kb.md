```markdown
# GS25 발주 정책 가이드

## 자동 발주 기본 규칙

### 발주 산출 공식
자동 발주량 = (일 평균 판매량 × 리드타임) + 안전재고 - 현재고

### 리드타임 기준
- 도시락/신선식품: 1일 (매일 배송)
- 음료/과자: 2일 (격일 배송)
- 생활용품: 3일 (주 2회 배송)

### 안전재고 기준
- 도시락: 일 평균 판매량의 20%
- 음료: 일 평균 판매량의 30%
- 과자: 일 평균 판매량의 25%
- 생활용품: 일 평균 판매량의 50%

## 발주 승인 프로세스
1. 시스템이 자동 발주량 산출
2. 점주가 발주 내역 검토
3. 수량 조정 가능 (±50% 범위 내)
4. 최종 승인 후 발주 확정
5. 배송 센터에서 다음 배송일에 배송

## 특수 상황 발주
- 행사 기간: 해당 상품 발주량 1.5배 적용
- 날씨 연동: 기온 30도 이상 시 음료 카테고리 1.3배
- 비 예보 시: 우산, 우비 카테고리 자동 발주량 증가
- 주말/공휴일: 도시락 카테고리 1.2배 적용

## 폐기 관리
- 유통기한 임박 상품 (4시간 이내): 자동 할인 적용 (30%)
- 유통기한 만료 상품: 즉시 폐기 처리
- 월간 폐기율 5% 이상 시 발주량 자동 조정
```

## Step 2: S3에 문서 업로드

### S3 버킷 만들기

1. AWS 콘솔에서 **S3** 서비스로 이동
2. **버킷 만들기** 클릭
3. 설정:
   * 버킷 이름: `gs25-kb-data-{본인계정ID}` (전 세계에서 고유해야 함)
   * 리전: **us-east-1** (N. Virginia)
   * 나머지는 기본값 그대로
4. **버킷 만들기** 클릭

### 파일 올리기

1. 방금 만든 버킷 클릭
2. **업로드** 클릭
3. 위에서 만든 3개의 `.md` 파일을 **드래그 앤 드롭**
4. **업로드** 클릭

{% hint style="warning" %}
버킷 리전을 반드시 **us-east-1**로 설정하세요! Bedrock Knowledge Base와 같은 리전이어야 합니다.
{% endhint %}

## Step 3: Knowledge Base 만들기

### Bedrock 콘솔에서 생성

1. AWS 콘솔에서 **Amazon Bedrock** 서비스로 이동 (리전: us-east-1)
2. 좌측 메뉴에서 **Knowledge bases** 클릭
3. **Create knowledge base** 클릭
4. **Knowledge base with vector store** 선택

### 기본 정보 입력

| 항목          | 입력값                                      |
| ----------- | ---------------------------------------- |
| Name        | `gs25-knowledge-base`                    |
| Description | `GS25 편의점 운영 정보 Knowledge Base`          |
| IAM role    | **Create and use a new service role** 선택 |

**Next** 클릭

### 데이터 소스 설정

| 항목               | 입력값                           |
| ---------------- | ----------------------------- |
| Data source name | `gs25-s3-data`                |
| S3 URI           | `s3://gs25-kb-data-{본인계정ID}/` |

**Next** 클릭

### 임베딩 모델 & 벡터 스토어

| 항목               | 입력값                                    |
| ---------------- | -------------------------------------- |
| Embeddings model | **Titan Text Embeddings V2**           |
| Vector store     | **Quick create a new vector store** 선택 |

{% hint style="info" %}
**Quick create**를 선택하면 Amazon OpenSearch Serverless가 자동으로 만들어집니다. 복잡한 설정이 필요 없어요!
{% endhint %}

**Next** 클릭 → 설정 확인 → **Create knowledge base** 클릭

### 데이터 동기화 (Sync)

Knowledge Base가 만들어지면 (약 1\~2분):

1. 생성된 Knowledge Base 페이지에서 **Data source** 섹션 확인
2. 데이터 소스를 선택하고 **Sync** 클릭
3. 완료될 때까지 대기 (약 1\~3분)

{% hint style="success" %}
Status가 **Available**로 바뀌면 완성! 문서가 검색 가능한 상태가 되었습니다.
{% endhint %}
