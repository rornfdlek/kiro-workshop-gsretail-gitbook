# Knowledge Base 테스트

## 콘솔에서 바로 테스트

Knowledge Base 상세 페이지 오른쪽에 **테스트 패널**이 있습니다.

### 테스트 방법

1. 오른쪽 **Test knowledge base** 패널 확인
2. **Select model** 클릭 → **Claude 3.5 Sonnet** (또는 Claude 3 Haiku) 선택
3. 아래 질문들을 하나씩 입력해보세요!

## 이것만 확인하세요

| 확인 항목 | 잘 되고 있다면 |
|-----------|--------------|
| **답변이 정확한가?** | 우리가 올린 문서 내용과 일치하는 답변 |
| **출처가 보이는가?** | 답변 아래에 참조 문서(Source) 표시 |
| **모르는 건 모른다고 하는가?** | 문서에 없는 내용을 지어내지 않음 |

## RAG가 동작하는 모습

테스트 패널에서 **Show source details**를 켜면, AI가 어떤 문서를 참고했는지 볼 수 있습니다:

```
점주: "도시락 자동 발주량은 어떻게 계산해?"

[AI가 찾은 문서 조각]
📄 gs25_order_policy.md: "자동 발주량 = (일 평균 판매량 × 리드타임) + 안전재고 - 현재고"
📄 gs25_order_policy.md: "도시락/신선식품: 1일 (매일 배송)"

[AI 답변]
"도시락의 자동 발주량은 다음 공식으로 계산됩니다:
자동 발주량 = (일 평균 판매량 × 1일) + 안전재고(20%) - 현재고
예를 들어 김치찌개 도시락의 경우..."
```

이것이 RAG의 핵심입니다:

1. 질문과 관련된 문서를 **자동으로 찾고**
2. 찾은 문서를 AI에게 **컨텍스트로 전달**하여
3. **근거 있는 답변**을 생성합니다
