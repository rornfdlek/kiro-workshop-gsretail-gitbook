# Requirements - 요구사항 문서 생성

## 요구사항 문서 작성 요청

Kiro 채팅 패널에 아래 프롬프트를 입력하여 요구사항 문서 작성을 시작합니다.

{% code title="프롬프트" %}
```
requirements를 작성해주세요.
```
{% endcode %}

{% hint style="info" %}
Kiro가 이전에 입력한 모든 프롬프트 컨텍스트(프로젝트 소개, 기술스택, DB 설계, 주요 기능 등)를 종합하여 `requirements.md` 파일을 자동 생성합니다.
{% endhint %}

## 생성되는 문서 확인

Kiro가 생성하는 `requirements.md` 파일에는 다음 내용이 포함됩니다:

* **프로젝트 개요**: GS25 발주 자동화 시스템의 목적과 범위
* **기능 요구사항**: 발주 자동 계산, 승인/수정, 재고 모니터링, 대시보드
* **기술 요구사항**: React, Express, SQLite, Chart.js 등
* **데이터 모델**: product, inventory, sales\_history, order 테이블
* **비기능 요구사항**: 로컬 환경 실행, AWS 전환 용이성

## 요구사항 검토 포인트

문서가 생성되면 아래 항목들을 확인해보세요:

| 확인 항목 | 설명 |
|-----------|------|
| 기능 범위 | 핵심 기능 4가지가 포함되어 있는가? |
| 기술스택 | 입력한 기술스택이 반영되었는가? |
| DB 테이블 | 4개 테이블이 모두 포함되었는가? |
| 로컬 환경 | AWS 의존 없이 로컬 실행 가능한 구조인가? |
| 시뮬레이터 | 판매 데이터 시뮬레이터가 포함되었는가? |

{% hint style="warning" %}
요구사항이 너무 많거나 복잡하다면, 이전 단계에서 입력한 간소화 요청이 잘 반영되었는지 확인하세요. 필요하다면 추가로 간소화를 요청할 수 있습니다.
{% endhint %}
