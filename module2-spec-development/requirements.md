# Requirements - 요구사항 문서 생성

## 요구사항 문서란?

> "이 시스템에는 이런 기능이 있어야 합니다"를 정리한 문서입니다.

식당에 비유하면, 메뉴판을 만드는 과정입니다. "우리 식당에서는 김치찌개, 된장찌개, 비빔밥을 팝니다"처럼, 시스템이 할 수 있는 일을 목록으로 정리합니다.

## 프롬프트 보내기

아래 프롬프트를 Kiro 채팅창에 입력합니다:

{% code title="📋 복사해서 붙여넣기" %}
```
requirements를 작성해주세요.
```
{% endcode %}

{% hint style="info" %}
**짧은 한 줄이지만 강력합니다!** Kiro는 이전에 여러분이 입력한 모든 내용(프로젝트 소개, 기술스택, DB 설계, 기능 목록 등)을 기억하고 있어서, 이 한 줄만으로 완전한 요구사항 문서를 만들어냅니다.
{% endhint %}

## 잠시 기다리면...

Kiro가 `requirements.md` 파일을 자동으로 생성합니다! 이 문서에는:

* **프로젝트 개요** — GS25 발주 자동화 시스템이 뭔지
* **기능 목록** — 자동 발주, 재고 모니터링, 대시보드 등
* **기술 정보** — React, Express, SQLite 등
* **데이터 구조** — 4개의 테이블(상품, 재고, 판매, 발주)

## 문서 확인 체크리스트

생성된 문서가 괜찮은지 아래 항목을 체크해보세요:

| ✅ | 확인 항목 | 의미 |
|----|-----------|------|
| ☐ | 핵심 기능 4가지가 있는가? | 발주계산, 승인, 재고, 대시보드 |
| ☐ | 4개 테이블이 있는가? | product, inventory, sales\_history, order |
| ☐ | "로컬에서 실행" 언급이 있는가? | AWS 없이 내 노트북에서 동작 |
| ☐ | 시뮬레이터가 포함되어 있는가? | 가상 판매 데이터 생성 기능 |

{% hint style="warning" %}
요구사항이 너무 많아 보인다면? "좀 더 줄여주세요"라고 Kiro에게 추가 메시지를 보내면 됩니다.
{% endhint %}
