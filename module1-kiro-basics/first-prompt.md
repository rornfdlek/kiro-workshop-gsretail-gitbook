# 프로젝트 시작 - 첫 번째 프롬프트

## Kiro IDE 실행

1. Kiro를 실행합니다.
2. **새 폴더**를 생성하거나 빈 폴더를 열어 프로젝트를 시작합니다.
3. Kiro의 채팅 패널이 좌측에 표시되는지 확인합니다.

{% hint style="info" %}
Kiro의 채팅 패널에서 자연어로 프롬프트를 입력하면, Spec-driven Development 워크플로우가 자동으로 시작됩니다.
{% endhint %}

## 첫 번째 프롬프트 입력

Kiro 채팅 패널에 아래 프롬프트를 입력합니다. 이것이 프로젝트의 **제작 의도**를 설명하는 첫 번째 단계입니다.

{% code title="프롬프트" %}
```
GS25 Auto Order
GS Retail의 편의점(GS25) 발주 자동화 시스템을 구축합니다.
판매 데이터와 재고 현황을 기반으로 최적의 발주량을 자동 계산하고, 점주가 웹에서 발주를 승인/수정할 수 있는 풀스택 웹 애플리케이션입니다.
대상 상품은 도시락, 음료, 과자, 생활용품 등 편의점 주요 카테고리 상품입니다.
지금부터 세부내용들에 대해 말하겠습니다. 앞으로 작업하는 문서들은 모두 한글로 해주세요.
```
{% endcode %}

{% hint style="info" %}
프롬프트를 입력한 후 Kiro가 응답할 때까지 잠시 기다려주세요. Kiro가 프로젝트 컨텍스트를 이해하고 있음을 확인할 수 있습니다.
{% endhint %}
