# 프로젝트 시작 - 첫 번째 프롬프트

## Kiro 채팅창 찾기

Kiro를 열면 **왼쪽에 채팅 패널**이 보입니다. 여기에 메시지를 입력하면 됩니다.

{% hint style="info" %}
카카오톡에 메시지 보내는 것과 같습니다! 채팅창에 글을 입력하고 Enter(또는 전송 버튼)를 누르면 됩니다.
{% endhint %}

## 첫 번째 프롬프트 보내기

아래 텍스트를 **그대로 복사**해서 Kiro 채팅창에 붙여넣고 전송합니다:

{% code title="📋 복사해서 붙여넣기" %}
```
GS25 Auto Order
GS Retail의 편의점(GS25) 발주 자동화 시스템을 구축합니다.
판매 데이터와 재고 현황을 기반으로 최적의 발주량을 자동 계산하고, 점주가 웹에서 발주를 승인/수정할 수 있는 풀스택 웹 애플리케이션입니다.
대상 상품은 도시락, 음료, 과자, 생활용품 등 편의점 주요 카테고리 상품입니다.
지금부터 세부내용들에 대해 말하겠습니다. 앞으로 작업하는 문서들은 모두 한글로 해주세요.
```
{% endcode %}

### 이 프롬프트가 하는 일

| 문장                  | 역할                      |
| ------------------- | ----------------------- |
| "GS25 Auto Order"   | 프로젝트 이름을 정해줍니다          |
| "발주 자동화 시스템을 구축합니다" | 어떤 시스템인지 알려줍니다          |
| "점주가 웹에서 발주를 승인/수정" | 누가, 어떻게 사용하는지 설명합니다     |
| "도시락, 음료, 과자, 생활용품" | 대상 상품 종류를 알려줍니다         |
| "한글로 해주세요"          | Kiro가 한국어로 문서를 작성하게 합니다 |

{% hint style="warning" %}
프롬프트를 보낸 후 Kiro가 응답할 때까지 **10\~30초 정도** 기다려주세요. Kiro가 프로젝트를 이해하고 있다는 메시지가 나오면 성공입니다!
