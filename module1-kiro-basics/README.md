# Module 1: Kiro 시작하기

## 이 모듈에서 할 것

Kiro에게 **"이런 시스템을 만들어줘"**라고 설명하는 단계입니다.

한 번에 모든 걸 말하면 Kiro가 헷갈릴 수 있기 때문에, **단계별로 나누어** 설명합니다:

| 단계 | 뭘 하나요? | 비유 |
|------|-----------|------|
| 첫 번째 프롬프트 | 프로젝트 소개 | "나 편의점 발주 시스템 만들 거야" |
| 기술스택 | 사용할 도구 선택 | "레시피에 어떤 재료를 쓸지 알려주기" |
| DB 설계 | 저장할 데이터 설명 | "어떤 정보를 기록할지 정하기" |
| 주요 기능 | 필요한 기능 설명 | "어떤 기능이 있으면 좋겠는지 설명" |
| 환경 설정 | 실행 환경 설명 | "내 노트북에서 돌려줘" |

{% hint style="info" %}
**프롬프트를 잘 쓰는 팁**: 구체적으로 쓸수록 Kiro가 더 정확하게 만들어줍니다. "맛있는 거 만들어줘" 보다 "김치찌개 2인분 만들어줘"가 좋은 것처럼요!
{% endhint %}
